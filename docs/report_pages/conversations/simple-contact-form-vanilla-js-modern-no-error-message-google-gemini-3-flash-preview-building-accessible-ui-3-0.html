User

Build a contact form for a support page with text inputs for full name, email address, and phone number.

Requirements:
- Use plain HTML, CSS, and vanilla JavaScript.
- Give the page a clean, modern product design.
- Do not show inline validation messages on initial render.
- Keep full name and email address required.
- Keep phone number optional.
- Wrap each field in a div with class "form-field".
- The phone number field MUST have helper text that describes the expected format.
- Include a submit button.


Save your answer to `index.html`. Feel free to use separate CSS and JS files in the same directory.
